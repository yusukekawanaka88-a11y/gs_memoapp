# ①課題名
ClipStock（定型文管理アプリ）

## ②課題内容（どんな作品か）
- よく使う文章を登録・保存できる定型文管理アプリです。
- タイトルと本文を入力すると、登録した定型文がカード形式で一覧表示されます。
- localStorageを利用しているため、ブラウザを閉じても登録した文章が保存されます。

## ③アプリのデプロイURL
未デプロイ

## ④アプリのログイン用IDまたはPassword（ある場合）
なし

## ⑤工夫した点・こだわった点
- 普段の業務でよく使う定型文を簡単に管理できるよう、Clipyを参考にWebアプリとして制作しました。
- 配列やfor文など、講義で学習した内容を活用することを意識しました。
- localStorageを使用し、ページを再読み込みしても登録した文章が残るようにしました。
- シンプルで使いやすい画面を目指し、定型文をカード形式で表示するデザインにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- localStorageへのデータ保存と、保存したデータを読み込んで画面に表示する処理の理解が難しかったです。
- for文を使って、保存されている複数の定型文を繰り返し表示する部分に苦戦しました。
- お気に入り登録や定型文の編集・削除機能も実装し、より実用的なアプリにしていきたいです。
